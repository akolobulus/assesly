# **App Name**: FormFlow

## Core Features:

- Landing Page: Landing page with hero section, mini-features, main features, how it works, why us, target audience, FAQ, CTA, and footer.
- Pricing Plans: Pricing section with Free, Pro, and Enterprise plans.
- User Authentication: User authentication using Firebase Authentication (Email/Password and Google OAuth) with signup, login, and recover password pages.
- User Dashboard: User dashboard with a responsive and collapsible sidebar.
- Form Builder: Form builder with drag-and-drop functionality and movable form fields.
- Responsive Preview: Responsive preview mode for desktop, tablet, and mobile views in form builder.
- Theme Selection: Dark, Light, and System theme modes to suit user preferences.

## Style Guidelines:

- Primary color: Scarlet Red (#D8130E). It is bold, matches a color the user provided, and offers excellent contrast.
- Background color: Cloud White (#F8F8FA). It's close in hue to scarlet, and produces a high contrast, light design.
- Accent color: Pale Red (#FBE1E0). It complements the scarlet with an analogous, desaturated contrast.
- Figtree font for clear and modern text presentation, as requested.
- Responsive design with breakpoints for desktop, tablet, and mobile.
- Use consistent and modern icons to represent different form elements and actions.
